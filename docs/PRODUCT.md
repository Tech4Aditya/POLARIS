# POLARIS Product Blueprint

## North star

Discover → Understand → Verify → Communicate.

## Core modules

1. Polar Archive
2. Expedition Explorer
3. Dataset Registry
4. Multimedia Library
5. Polar Map
6. Polar Knowledge Engine
7. Content Studio
8. Editorial Review
9. Smart Education

## Trust rule

Generated content must be grounded in indexed sources. Every factual claim shown
to a reviewer should be traceable to a source document/chunk where possible.

## Demo narrative

A visitor searches for a polar research topic → discovers a report → opens source
passages → asks the Knowledge Engine a question → generates a public-facing article
→ sees source coverage → reviewer approves → content becomes publishable.
